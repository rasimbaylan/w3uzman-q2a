# W3Uzman Q2A - archival source snapshot

This repository contains a filtered source snapshot from the 2019 W3Uzman archive. The source archive date is 2019-10-24; the Git commit records when this snapshot was imported, not when the original changes were made.

This is historical code derived from Question2Answer. It is not the newer Wuzman Laravel project. Credentials, private configuration, databases, uploads, backups and unrelated test sites were excluded. Some assets and optional files have also been excluded while reviewing the archive. Installation, security and completeness have not yet been verified. Do not deploy this snapshot as-is.
